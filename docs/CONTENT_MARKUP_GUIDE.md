# MoneyPet 콘텐츠 마크업 가이드

## 개요
백오피스에서 학습 콘텐츠 및 퀴즈를 입력할 때 사용하는 마크업 문법입니다. WYSIWYG 에디터를 통해 간편하게 텍스트 서식을 적용할 수 있습니다.

**🎉 2026-01-04 업데이트**: WYSIWYG 에디터 및 실시간 미리보기 구현 완료!

---

## 현재 지원 문법 (v2.0)

### 1. 볼드 (굵게) - `**텍스트**`

키워드나 중요한 용어를 강조할 때 사용합니다.

**입력 예시:**
```
**예금**은 자유롭게 입출금이 가능하고, **적금**은 정해진 기간 동안 저축해요.
```

**앱에서 표시:**
- "예금"과 "적금"이 W700 (Bold) 굵기로 표시됩니다
- 나머지 텍스트는 W500 (Medium) 굵기로 표시됩니다

**사용 가이드:**
- ✅ 금융 용어, 핵심 개념에 사용
- ✅ 한 문장에 2-3개 키워드 강조
- ❌ 전체 문장을 볼드 처리하지 마세요
- ❌ 볼드를 과도하게 사용하지 마세요

---

### 2. 이탤릭 (기울임) - `*텍스트*`

부가 설명이나 보조 정보를 표시할 때 사용합니다.

**입력 예시:**
```
예금은 *언제든 찾을 수 있는* 상품이에요.
```

**앱에서 표시:**
- "언제든 찾을 수 있는"이 기울임꼴로 표시됩니다

**WYSIWYG 에디터:**
- 텍스트 선택 → Italic 버튼 클릭

---

### 3. 밑줄 - `__텍스트__`

특정 내용을 시각적으로 강조할 때 사용합니다.

**입력 예시:**
```
__주의사항__: 중도 해지 시 이자가 줄어들어요.
```

**앱에서 표시:**
- "주의사항"에 밑줄이 표시됩니다

**WYSIWYG 에디터:**
- 텍스트 선택 → Underline 버튼 클릭 (자동으로 `__텍스트__` 삽입)

---

### 4. 취소선 - `~~텍스트~~`

잘못된 정보나 수정된 내용을 표시할 때 사용합니다.

**입력 예시:**
```
~~100만원~~ → 150만원으로 변경되었어요.
```

**앱에서 표시:**
- "100만원"에 취소선이 표시됩니다

**WYSIWYG 에디터:**
- 텍스트 선택 → Strikethrough 버튼 클릭

---

### 5. 색상 지정 - `[color:#HEX코드]텍스트[/color]`

**입력 예시:**
```
[color:#9F7AEA]예금[/color]과 [color:#48BB78]적금[/color]의 차이를 알아봐요.
```

**앱에서 표시:**
- "예금"은 보라색(#9F7AEA)
- "적금"은 초록색(#48BB78)

**사용 가능한 색상 (앱 컬러 팔레트):**
- `#9F7AEA` - 메인 보라
- `#48BB78` - 초록
- `#F56565` - 빨강
- `#ED8936` - 주황
- `#4299E1` - 파랑
- `#718096` - 회색

**WYSIWYG 에디터:**
- 텍스트 선택 → Palette 버튼 클릭 → 색상 선택 (3x2 그리드)

---

### 6. 텍스트 크기 - `[size:숫자]텍스트[/size]`

**입력 예시:**
```
[size:20]중요 포인트![/size] 복리는 눈덩이처럼 불어나요.
```

**권장 크기:**
- `20` - 강조 제목 (large)
- `17` - 본문 (normal, 기본값)
- `14` - 작은 설명 (small)

**WYSIWYG 에디터:**
- 텍스트 선택 → Type 버튼 클릭 → 크기 선택 (드롭다운)
- large/normal/small 선택 시 자동으로 숫자 마크업 생성

---

### 7. 복합 사용

**입력 예시:**
```
**[color:#9F7AEA]예금[/color]**은 [size:14]언제든 찾을 수 있어요[/size]
__핵심__: *중요한 개념*을 잘 기억해요.
```

## 실제 사용 예시

### 예시 1: 기본 학습 콘텐츠
```
**예금**과 **적금**은 모두 은행에 돈을 맡기는 방법이에요.

**예금**은 자유롭게 입출금이 가능하고,
**적금**은 정해진 기간 동안 꾸준히 저축해요.
```

### 예시 2: Tip 영역
```
💡 **복리**의 힘은 시간이 지날수록 커져요.
100만원을 연 5%로 10년간 저축하면 **162만원**이 됩니다!
```

### 예시 3: 향후 색상 사용 (예정)
```
금리에는 두 가지가 있어요.

[color:#48BB78]**단리**[/color]는 원금에만 이자가 붙고,
[color:#9F7AEA]**복리**[/color]는 이자에도 이자가 붙어요!
```

## 마크업 파싱 로직

### 현재 구현 (v1.0)
```dart
// **텍스트** 패턴 인식
final boldPattern = RegExp(r'\*\*(.+?)\*\*');

// TextSpan으로 변환
TextSpan(
  text: '볼드 텍스트',
  style: baseStyle.copyWith(fontWeight: FontWeight.w700),
)
```

### 현재 구현 (v2.0) - ✅ 완료
```dart
// 6가지 마크업 통합 정규식 (lib/utils/text_renderer.dart)
final pattern = RegExp(
  r'\*\*(.+?)\*\*|'                              // 볼드
  r'(?<!\*)\*(?!\*)(.+?)\*(?!\*)|'               // 이탤릭
  r'__(.+?)__|'                                   // 밑줄
  r'~~(.+?)~~|'                                   // 취소선
  r'\[color:(#[0-9A-Fa-f]{6})\](.+?)\[/color\]|' // 색상
  r'\[size:(\d+)\](.+?)\[/size\]',               // 크기
);
```

## 주의사항

### ✅ 권장사항
1. **키워드 중심 강조**: 금융 용어, 핵심 개념만 볼드 처리
2. **적절한 사용**: 한 문장에 2-3개 키워드만 강조
3. **일관성 유지**: 같은 용어는 항상 같은 방식으로 강조
4. **가독성 우선**: 과도한 서식은 피하기

### ❌ 피해야 할 것
1. 전체 문장을 볼드 처리
2. 한 문장에 5개 이상 키워드 강조
3. 의미 없는 단어에 볼드 사용
4. 마크업 태그를 잘못 닫기 (예: `**텍스트*`)

### 올바른 예시
```
**예금**은 자유롭게 입출금이 가능하고, **적금**은 정해진 기간 동안 저축해요.
```

### 잘못된 예시
```
**예금은 자유롭게 입출금이 가능하고, 적금은 정해진 기간 동안 저축해요.**
(전체가 볼드 처리되어 강조 효과 없음)
```
